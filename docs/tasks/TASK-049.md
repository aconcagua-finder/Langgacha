## Часть 1 — Анализ качества существующих 150 слов

**Входные файлы:**
- `backend/scripts/seed-words-common.ts` (75 слов, C)
- `backend/scripts/seed-words-uncommon.ts` (45 слов, UC)
- `backend/scripts/seed-words-rare.ts` (20 слов, R)
- `backend/scripts/seed-words-sr.ts` (10 слов, SR)

**Что проверяем для каждого слова:**

| Поле | Критерии |
|------|----------|
| `word` | Корректное написание, нет опечаток |
| `translationRu` | Точный перевод, не слишком широкое/узкое толкование, нет лишних нюансов в скобках если можно обойтись |
| `type` | Соответствует ли реально (Place/Action/Object/Person/Emotion/Expression) |
| `rarity` | Адекватна ли — не попало ли базовое слово в R, и наоборот |
| `flavorText` | Грамматически валиден? Звучит естественно? Контекст уместен? Не слишком длинный? |
| `hint` (мнемоника) | Работает ли ассоциация? Не грубая, не притянутая? Помогает запомнить именно ЭТО значение? |
| `quizOptions` | 1) Правильный ответ включён и помечен `quizCorrect`? 2) Дистракторы не синонимы правильного? 3) Дистракторы слишком очевидны или нормальные? 4) Семантически близки (если нет — это ок для C, но плохо для R/SR) |
| `tags` | Существующие теги хаотичные — отмечать не нужно, всё равно заменим. Но проверить что вообще есть ли смысловая нагрузка |
| `conceptKey` | Англ. ключ отражает концепт? Консистентный? (напр. для `cocinar` должен быть `cook`, не `cooking` или `cocinar`) |

**Формат выходного отчёта:** новый файл `docs/content-audit.md` со структурой:

```markdown
# Content Audit — 150 существующих слов

## Общая статистика
- Всего слов: 150 (75C / 45UC / 20R / 10SR)
- Слов с проблемами: N

## Категории проблем

### 🔴 Критичные (нужно править обязательно)
1. **casa** (`seed-words-common.ts:5-20`)
   - Проблема: hint "Casa звучит как касса" — натянуто, не работает
   - Предложение: "Casa → «каса» почти как «каса-бланка», белый дом" ИЛИ другое
2. ...

### 🟡 Улучшения (желательно)
1. ...

### 🟢 Эталонные (можно брать как reference для AI-промпта)
- **laburar**, **boludo**, ... — перечислить 15-20 лучших

## Систематические проблемы
- Большинство дистракторов в translate-квизах попадают случайно из всего пула, а не семантически. Для C это ок, для R/SR нужно пересобрать.
- `conceptKey` не всегда консистентен: ...
- ...

## Предложения по процессу
- ...
```
